# Organization Logos

This directory contains logos for organizations mentioned in the CV timeline.

## Required Logo Files:

- `microsoft.png` - Microsoft Research Asia logo
- `amazon.png` - Amazon logo  
- `yonsei.png` - Yonsei University logo
- `ucsc.png` - UC Santa Cruz logo

## Logo Requirements:

- Format: PNG or SVG
- Size: 24x24px recommended (will be automatically resized)
- Background: Transparent preferred
- Quality: High resolution for retina displays

## Usage:

Logos are automatically displayed in the CV timeline when the `logo` field is specified in `_data/cv.yml`.

Example:
```yaml
- title: Research Scientist Intern
  institution: Microsoft Research Asia (MSRA)
  year: Jun 2025 - Dec 2025
  logo: microsoft.png
```
